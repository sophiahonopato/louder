# LOUDER (React + Vite + Framer Motion)
1. Instale o Node.js (https://nodejs.org) — versão 18 ou mais nova.
2. No terminal do VS Code (Ctrl+'), dentro desta pasta: `npm install`
3. Rode: `npm run dev` e abra o link que aparecer (http://localhost:5173)
4. Para publicar: `npm run build` (gera a pasta dist/)
Edite textos em src/App.jsx (listas no topo) e estilos em src/index.css.
